## Hi there 👋

This repository contains a minimal ASP.NET Core Razor Pages demo showing a simple login page implemented in C#.

Run locally:

1. Install .NET SDK (8.0+ recommended): https://dotnet.microsoft.com/
2. From this repository folder run:

```bash
dotnet restore
dotnet run --project LoginPage.csproj
```

Open `https://localhost:5001` (or the URL shown in the console) and navigate to `/Login`.

Demo credentials:
- Email: `user@example.com`
- Password: `Pass123!`

Important: This project uses an in-memory demo authentication check in `Pages/Login.cshtml.cs`. Replace it with proper authentication (Identity, external provider, or your user store) before using in production.

```
